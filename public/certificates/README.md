# Certificate Upload Directory

Drop your certificate images into this folder (`project/public/certificates/`).

Supported formats: `.png`, `.jpg`, `.jpeg`, `.webp`

### Recommended filenames matching each certificate ID:
1. `nptel-java.png` (or `.jpg`) — Programming in Java (NPTEL)
2. `eduskills-java-fullstack.png` (or `.jpg`) — Java Full Stack (EduSkills)
3. `scaler-docker-k8s.png` (or `.jpg`) — Fundamentals of Docker & Kubernetes (Scaler)
4. `eduskills-security.png` (or `.jpg`) — Web Exploit Hunting (EduSkills)
5. `apexplanet-internship.png` (or `.jpg`) — Web Development Internship (ApexPlanet)
6. `deloitte-sim.png` (or `.jpg`) — Technology Job Simulation (Deloitte)
7. `jbrec-ai-chatbot.png` (or `.jpg`) — AI Chatbot Building (JBREC)
8. `embrizon-data-science.png` (or `.jpg`) — Data Science Intern (Embrizon)

Once you upload the files here, the portfolio will automatically render your certificates in the hover preview and full-view modals!
